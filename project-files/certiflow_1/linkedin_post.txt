💡 About the Project:
CertiFlow is an end-to-end smart certificate automation system powered by Microsoft 365 tools — Forms, Excel, SharePoint, Power Automate, and Outlook.

Key Highlights:
🔹 Captures participant data through Microsoft Forms
🔹 Filters attendance data from Excel
🔹 Automates personalized certificate emails using Power Automate
🔹 Stores all certificates and logs in SharePoint
🔹 Reduces manual effort and improves accuracy dramatically

👨‍💻 My Role:
I designed and built the complete Power Automate flow that runs the heart of CertiFlow.
✅ Integrated Microsoft Forms with Excel
✅ Added condition checks for participation status
✅ Generated individual HTML certificates
✅ Automated Outlook email delivery with attachments
✅ Updated SharePoint list with certificate links and status — all in one seamless flow!
